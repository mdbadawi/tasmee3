# مصحف الحفظ PWA — القرآن كاملا

- السور الـ114 مفعلة.
- 604 صفحة من مصحف المدينة QCF V2.
- بيانات الكلمات والسطور تُجلب من Quran.com API وتُخزن في Cache Storage.
- خطوط QCF تُخزن بالطريقة نفسها.
- زر «تنزيل الكل» يحفظ الصفحات الـ604 والخطوط للعمل دون إنترنت.
- إذا انقطع التنزيل، زر «استكمال» يتجاوز الملفات الموجودة ويكمل الناقص.

للتشغيل محليا:
```bash
python -m http.server 8080
```
وللتثبيت كـPWA انشر المشروع على HTTPS مثل GitHub Pages.


## زر تثبيت التطبيق
زر «تثبيت التطبيق» ظاهر دائما في الصفحة الرئيسية.
إذا كان المتصفح يدعم نافذة التثبيت المباشرة فستظهر عند الضغط.
وإلا يعرض التطبيق طريقة التثبيت من قائمة المتصفح.


## وضع التسميع والإحصاءات
- مفتاح عادي / تسميع داخل شريط القارئ.
- Word Assist وAyah Assist وخطأ يدوي وUndo وإنهاء جلسة.
- علامات ضعف مستقلة بصريا عن لون الحروف/التجويد.
- شفاء تدريجي لمواضع الضعف عند اجتيازها في جلسات لاحقة دون مساعدة.
- ملخص جلسة، إحصاءات حسب الصفحة/الحزب/الجزء، تاريخ ختمات، وأضعف المواضع.
- البيانات تحفظ محليا وتعمل Offline.


## تحديث v2 — تفاصيل الخطأ والآية

- كل Word Assist / Ayah Assist / Manual Error يحفظ رقم السورة والآية والموضع.
- نخزن نص الآية مرة واحدة فقط لكل آية ظهر فيها حدث، بدلا من تكراره مع كل خطأ.
- ملخص الجلسة يعرض نوع الحدث + رقم الآية + الآية كاملة.
- في Word Assist وManual Error تبرز الكلمة المقصودة داخل نص الآية.
- Ayah Assist يعرض الآية كاملة دون افتراض كلمة بعينها.
- شاشة الإحصاءات تحتوي سجلا تفصيليا للأخطاء والمساعدات، وسجل الجلسات يمكن فتحه لرؤية التفاصيل.
- أضعف المواضع تعرض الآية كاملة مع تمييز الكلمة في نقاط الضعف الخاصة بالكلمات.
- Manual Error يستهدف الكلمة التالية المخفية في مسار التسميع، يسجلها ثم يكشفها فورا ويبرزها لحظيا.
- كشف Manual Error لا يحتسب Word Assist.
- Undo بعد Manual Error يعيد الكلمة إلى حالتها المخفية إذا كان زر الخطأ هو الذي كشفها.


## تحديث v3 — علامات الضعف أوضح

- Word Assist يعطي الكلمة وميضا واضحا فور كشفها، حتى لو كانت علامات الضعف الدائمة مخفية.
- العلامة الدائمة للكلمة أصبحت أوضح بثلاث درجات، من غير تغيير لون الحروف نفسها، حتى تظل ألوان التجويد مستقلة.
- Ayah Assist يعطي فاصل الآية وميضا واضحا فور كشف الآية.
- فاصل الآية الذي عليه ضعف سابق أصبح له خلفية/حلقة أوضح بثلاث درجات.
- مؤشر موضع القراءة cursor-marker ما زال مستقلا عن علامة ضعف الآية.
