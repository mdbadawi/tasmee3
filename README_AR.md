# مصحف الحفظ — PWA

هذه النسخة تحوّل قارئ سورة البقرة إلى تطبيق ويب قابل للتثبيت على Android ويدعم العمل دون إنترنت بعد تنزيل البيانات.

## التشغيل
لا تفتح `index.html` مباشرة بصيغة `file://` لأن Service Worker وميزة التثبيت تحتاج HTTP/HTTPS.

للتجربة على الكمبيوتر:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التثبيت على الهاتف
ارفع محتويات المجلد كما هي إلى استضافة HTTPS مثل GitHub Pages أو Cloudflare Pages، ثم افتح الرابط من Chrome واضغط «تثبيت» أو Add to Home screen.

## الأوفلاين
من الصفحة الرئيسية اضغط «تنزيل» بجوار «البقرة دون إنترنت». سيحفظ Service Worker بيانات الصفحات 2–49 وخطوط QCF V2. كذلك فتح البقرة مرة كاملة يملأ التخزين تدريجيا.

## إضافة سورة لاحقا
ملف `surahs.js` يحتوي قائمة 114 سورة. فعّل السورة بوضع `enabled: true` وأضف لها:

- `firstPage`
- `lastPage`
- `ayahCount`
- `cacheVersion`

قارئ `reader.html` مكتوب ليستقبل `?surah=رقم_السورة`.


## السور المفعلة حاليا
- البقرة: الصفحات 2–49، 286 آية.
- سبأ: الصفحات 428–434، 54 آية.

يمكن تنزيل كل سورة مستقلة للعمل دون إنترنت من الشاشة الرئيسية.
